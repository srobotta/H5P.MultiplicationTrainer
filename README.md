# H5P Content type: Multiplication Trainer

This is a new content type for [H5P](https://h5p.org).

## Licence

The h5p package is provided unter the [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
licence.

## Use case
Train the 1x1 (multiplication table) in single tasks. The learner
is presented with single multiplication tasks and has to enter the
correct result. The learner may solve as many tasks as he can within
a certain time frame. When the time is up, the list of tasks with the
responses and the correct and wrong answers are listed and counted.

## Installation

Go to the [releases](https://github.com/srobotta/H5P.MultiplicationTrainer/releases)
and download the latest h5p file.

For a manually build from the current source code,
checkout this repository or download the zip and use the Python build
script to build the h5p package. The so created file
`Multiplication_Trainer-X.Y.Z.h5p` is the H5P file that can be used
at your preferred ecosystem where H5 content is displayed.
